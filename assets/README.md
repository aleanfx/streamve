# Assets de StreamVe

## Marca — guardá acá los dos logos que generaste

| Archivo | Qué es | Medida sugerida |
|---|---|---|
| `logo-mark.png` | La **S** roja sola, fondo transparente | alto 256 px |
| `favicon.png` | La misma S, cuadrada | 512×512 |
| `logo-full.png` | El lockup completo (S + STREAM VE) | ancho 1200 px |

La S sola va en la barra superior al lado del nombre; el favicon es el
ícono de la pestaña. El lockup completo todavía no se usa en la web —
guardalo igual, sirve para redes y para el estado de WhatsApp.

**Importante: fondo transparente**, no el negro del render. Si lo dejás
con fondo, se va a ver un cuadrado negro sobre la barra.

Mientras no estén, la barra muestra solo el nombre escrito. No se rompe.
